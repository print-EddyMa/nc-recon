## Where NC Recon stands today (2026-10-07, branch phase-j-ops, nothing committed from the last three passes)

**Shape.** One container (FastAPI API + job worker + built React app, same origin) behind Caddy for HTTPS. No database: results, labels, registry, audit log and caches are files on one volume; backups are a tar file (`run.py ops-backup`). Python 3.13, ONNX Runtime on CPU; Node 22 build of a React 19 / MapLibre 6 / deck.gl 9.4 app. 150 offline tests; CI runs tests, typecheck, lint, build, image build, pip-audit, npm audit (runtime deps), SBOMs.

**Pipeline per assessment** (`plan -> collect -> align -> process -> evidence -> cnn -> fusion`, 84 s for Old Fort's 2,206 structures on one CPU): event and windows from OpenFEMA; imagery pair chosen and date-checked (pre before incident, post inside day 0..250); footprints merged from FEMA USA Structures, OSM gap-fill and NSI points; per-building local alignment of outlines to roofs; co-registration residual, off-nadir, sun and cloud measured and charged against change evidence; evidence channels E1 xView2 CNN (label-only until calibrated), E2 robust pixel change, E4 blue tarp, E5 flood depth (no water-surface source on any reach yet); log-linear fusion with abstention rules; review queue with reasons; people displaced and tract need index; exports (GeoJSON, CSV+USNG, KML, GPKG, FileGDB, Survey123, brief, public tract summary with counts under 5 withheld).

**Live layers today**: USGS Water Data OGC API gauges, NOAA NWPS forecasts, NWS alerts, NHC storms, NCDOT DriveNC closures and cameras, radar (mesonet), FIRMS, and (added 2026-10-07 from this research) NC FIMAN gauges (791 in service, server-composed from NCEM's public ArcGIS layer, terms unstated so marked provisional), Duke Energy outages by county (about every 20 minutes, Duke territory only), FEMA ESF6 open shelters. Data-source health board with background re-probe, now 15 probes.

**Access and security today**: fail-closed bearer token for every structure-level route, no localhost trust, server refuses to start exposed without a token, audit log of responder actions (file, client address, action, area), per-client rate limits (30 writes / 600 reads / 120 feed requests a minute, X-Forwarded-For only when NCR_TRUST_PROXY=1), enforced Content Security Policy and security headers, fonts bundled (no Google Fonts), HSTS from Caddy, CI with pip-audit (clean), npm audit on shipped deps (clean; 7 dev-toolchain advisories need Tailwind 4), CycloneDX SBOMs. Container runs as a non-root user; root filesystem is writable; secrets come from .env; backups are a manual tar (run.py ops-backup). No SSO, one shared token (no per-user identity), no MFA, no RBAC roles, no field app, no offline mode, audit log retention unmanaged, licence ledger corrected today (USA Structures is CC BY 4.0; OSM footprint merge is likely an ODbL derivative database).

**Validation today**: none. No public structure-level ground truth for Helene in NC; the system reports "not yet validated" until analysts label (protocol targets >=300 TUNE and >=200 TEST labels per area). TEST areas (Chimney Rock, Canton, Burnsville, Marshall) are fenced from tuning.

**Eight towns assessed** (all unvalidated): Old Fort, Spruce Pine, Swannanoa (TUNE); Chimney Rock, Burnsville, Marshall, Canton (TEST); Marion (OPS). 7,649 structures, ~806 expected Major or Destroyed, 3,503 awaiting review.

**Known gaps written down by the team**: Census API key (seasonal homes), Earthdata/GEE accounts (OPERA, HLS), analyst labels, post-Helene lidar (E6), E8 road isolation, nighttime-lights outage proxy, E3 shadow/height, E7 wind, field-report ingest, coverage-gap analysis, offline PWA packs, QGIS project, Spanish UI, satellite collection planner; Marion and Spruce Pine outputs still carry duplicate structure ids until re-run.
