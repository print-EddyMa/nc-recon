# Screen-recording shot list

What actually needs a screen recording, versus an on-camera shot or the
standalone Blender render, across both video scripts. Full VO and framing
live in `docs/CAC_VIDEO_SCRIPT.md`; this folder pulls out only the app-capture
instructions so they're easy to grab on shoot day without hunting through the
full script.

| Beat | CAC script | NC Idea Challenge script | Capture type | File |
|---|---|---|---|---|

| Full Circle | Beat 07 | Beat 06/07 | On-camera — no screen recording | — |
| Closing scene | — | — | Standalone Blender render — no screen recording | — |

**Shoot order:** record the CAC beats first — `01`, `03`, `04`, `05`, and `06`
if you're using the code-editor option for that one. Beat 04's full take is
also the source footage the Idea Challenge cut trims down for its own
`04-after-the-storm.md` note, and `idea-04-why-it-matters.md` is best captured
as its own take right after, while the 3-D scene is already loaded on
screen — it's a live camera push-in, not something to fake by cropping the
Beat 04 footage in post.
