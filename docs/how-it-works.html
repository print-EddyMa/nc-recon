TerraTriage · how it works

Scoring every building after the storm

When a hurricane clears North Carolina, the question is which buildings to reach first. TerraTriage answers it one structure at a time, from satellite imagery, and is honest about the calls it is not sure of. Here is the whole method, with the numbers from a real run over Old Fort after Hurricane Helene.

The inputs

Two pictures of the same place, taken before and after the disaster. They are often different seasons, sometimes years apart. That gap is the hard part of the problem, and the reason a reviewer gets the last word later.

The four-level scale, in real imagery

Every building is placed on the xView2 damage scale. These are actual Old Fort structures, each shown before Helene and after, with the class the pipeline assigned.

What taught the model

Nothing is trained from scratch. The classifier learned on xBD, the xView2 dataset: about 850,000 hand-labeled building polygons across 19 disasters, on this same four-level scale. TerraTriage runs the pretrained xView2 CMU baseline (a ResNet50 classifier) at inference time.

Reading every building

Each OpenStreetMap footprint is cropped from both images and run through the classifier. The output is one damage class per building. Laid out together, the run tells you more than any single call.

All 764, one square each

Where the damage sits

Plotting each building at its real coordinates shows the pattern the histogram hides: the severe cases cluster along the creek and the west end of town, exactly where the flooding was worst.

Damage against size

The destroyed and major-damage buildings are smaller than the ones left standing. Lighter structures, older houses, outbuildings and mobile homes took the worst of it.

03

Knowing the unknowns

There is no ground truth on the day. Instead of trusting one model, TerraTriage runs a second, independent read and compares them. Where they disagree, the building is not published as certain. It goes to a person.

Model against second read

The CNN class on one axis, an independent change-detection pass on the other, counted for all 764 buildings. Cells on the diagonal are agreements.

One disagreement, up close

Building old_fort-000136, a 79 m² structure near the creek. The two reads split, so it went to the review queue with both opinions attached.

Review rate by call

The two reads agree on the easy calls. Where the CNN says destroyed, the second pass disagrees by two or more levels almost three quarters of the time, so nearly every destroyed call gets a human check.

Why this is the point. Publishing 603 buildings as high-confidence and routing 161 to a reviewer, rather than reporting all 764 as fact, is how humanitarian mapping teams run AI damage assessment in practice. A context prior can still nudge a borderline call, but only on a live flood-stage signal, never on the class itself.

The risk layer

The damage map is the aftermath. The risk layer is the hours before and during, when no satellite has passed yet. Twelve keyless government feeds, filtered to North Carolina.

Thirty years of North Carolina disasters

65 federal declarations since 1990: 28 hurricanes, 9 wildfires, the rest ice, flood and severe storms. The app's history timeline is built from this feed. For events that predate satellite coverage, it shows the archived NWS radar for that day instead.

05

In the field

The pipeline writes one GeoJSON file, a feature per building. The app turns that into a map a coordinator can move through, and a file another team can pick up. 

# one building, as the pipeline writes it
{
  "type": "Feature",
  "geometry": { "type": "Polygon", "coordinates": [ … ] },
  "properties": {
    "id": "old_fort-000136",
    "damage_class": 3,             # 0 none to 3 destroyed
    "confidence_tier": "review",
    "sources": { "cnn": 3, "heuristic": 0 }
  }
}
0 no damage 1 minor 2 major 3 destroyed

Read next to the risk layer and the thirty-year timeline, the pieces cover a disaster end to end: the first flood forecast, the radar coming ashore, the road closures, and the building damage. Built for North Carolina, structured to run anywhere Maxar publishes imagery.

Sources

Imagery: Maxar Open Data. Footprints: OpenStreetMap. Training data: xBD / xView2. Live feeds: NOAA NWPS and NWS, National Hurricane Center, USGS NWIS, NASA FIRMS, NCDOT DriveNC, NC State Climate Office CLOUDS API, OpenFEMA, Iowa Environmental Mesonet. Damage model: the xView2 CMU baseline classifier, fused with an independent change-detection pass and North Carolina context priors.

Every figure here is measured from an actual TerraTriage run. Nothing is placeholder.
